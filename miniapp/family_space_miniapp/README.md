# Family Space — Telegram Mini App demo

## Файлы
- `index.html` — главная с выбором пространства
- `martin.html` — дашборд Мартина
- `lena.html` — дашборд Лены
- `schedule.html` — демо расписания
- `tasks.html` — интерактивный список заданий
- `styles.css` — стили и анимации
- `app.js` — логика страниц, Telegram WebApp API и рендер
- `data.json` — примеры данных (можно редактировать)

## Запуск локально
Не открывайте HTML как `file://`, поскольку `fetch('data.json')` требует сервер.
Запустите из папки проекта:
```bash
python3 -m http.server 8000
```
Откройте `http://localhost:8000`.

## Telegram
Для интеграции с Telegram Mini App:
1. Разместите файлы на HTTPS-хостинге.
2. В BotFather создайте/настройте бота и Mini App URL.
3. Вставьте официальный Telegram WebApp SDK перед `app.js` (см. ниже):
```html
<script src="https://telegram.org/js/telegram-web-app.js"></script>
<script src="app.js"></script>
```
4. Подключите серверную авторизацию через `initData` перед использованием реальных пользовательских данных.

## Примечания
Это frontend-прототип. Отметки задач и добавление занятий показывают демо-поведение, данные не сохраняются после перезагрузки. Свайп-поддержка и серверная синхронизация — следующий этап. Цвет сроков: зелёный — больше недели, жёлтый — 3–7 дней, красный — менее 3 дней или просрочка.
