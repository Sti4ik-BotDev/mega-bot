# 🤖 Мега-бот для Telegram

Универсальный бот для управления бизнесом, учёбой и домом.

## Функции

- 💼 **Бизнес**: управление клиентами, лиды с Авито
- 📚 **Учёба**: расписание занятий группы ТП1-926
- 🏡 **Дом**: списки покупок и задачи
- 🤖 **AI**: интеграция с Kiro (в разработке)

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

## Переменные окружения

Создай файл `.env`:

```env
TOKEN=твой_telegram_bot_token
YANDEX_TOKEN=твой_yandex_token
YANDEX_SCHEDULE_URL=ссылка_на_папку
STUDENT_GROUP=ТП1-926
```

## Деплой на Render.com

1. Создай аккаунт на render.com
2. Подключи GitHub репозиторий
3. Добавь переменные окружения
4. Деплой!
