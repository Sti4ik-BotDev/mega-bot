## 🚀 Как пользоваться

### Первый запуск
1. Открой Telegram
2. Найди бота: **@shabashkanaxyi_bot**
3. Нажми `/start`
4. Выбери раздел в меню

### Основные разделы

#### 💼 Мой бизнес
```
🔥 Топ клиенты - с кого начать писать прямо сейчас
📋 Все контакты - полная база
🕐 Ждут ответа - кому пора писать follow-up
🔵 В работе - переговоры идут
💰 Продажи - закрытые сделки
🎯 Лиды с Авито - новые контакты
```

**Как работать с клиентом:**
1. Выбери клиента из списка
2. Нажми на телефон/Telegram/WhatsApp → открывается напрямую
3. Скопируй готовый скрипт
4. Отправь клиенту
5. Обнови статус: "✅ Написал" → "🔵 В работе" → "💰 Продано"

#### 📚 Учёба
```
📅 Расписание на сегодня - пары на день
📅 Расписание на завтра - планируй заранее
📅 Расписание на неделю - вся неделя сразу
🔄 Обновить расписание - скачать свежее с Яндекс Диска
```

**Расписание показывает:**
- ⏰ Время каждой пары
- 📚 Предмет
- 👨‍🏫 Преподаватель
- 🚪 Аудитория

**Автообновление:**
- Каждый день в **7:00** бот сам качает новое расписание
- Если что-то изменилось - увидишь сразу

#### 🏡 Дом
```
🛒 Список покупок - что купить
✅ Задачи - что сделать
➕ Добавить покупку
➕ Добавить задачу
```

**Как использовать:**
1. Кто-то добавляет покупку/задачу
2. Оба видите в боте
3. Купили/сделали → отметить выполненным
4. Очистить список

### Как запустить бота вручную
```bash
# Вариант 1: через батник
start-mega.bat

# Вариант 2: через командную строку
cd G:\AI-Projects\CRM-BOT
node mega-bot.js
```

### Как остановить бота
```bash
# Найти процесс
tasklist | findstr node

# Убить процесс (PID из списка)
taskkill /F /PID 14132
```

- Если есть новое расписание — скачивает
- Парсит группу **ТП1-926**
- Обновляет данные

## 📞 Частые вопросы

**Q: Бот не отвечает**
A: Проверь запущен ли бот. Запусти `start-mega.bat`

**Q: Расписание не обновляется**
A: Нажми "🔄 Обновить расписание" вручную

**Q: Как добавить нового клиента?**
A: Отредактируй файл `clients.json` или скажи мне - я добавлю

**Q: Девушка не видит расписание**
A: Пусть напишет боту `/start` в Telegram

**Q: Можно ли использовать с телефона?**
A: Да! Весь бот работает в Telegram, доступен где угодно

**Q: Как сделать чтобы бот работал всегда?**
A: Держи компьютер включённым или перенеси на VPS сервер
